# Attributions

## Sound Assets

### Ambient Sounds
The 38 ambient recordings in the table below are derived from [Moodist](https://github.com/remvze/moodist) (pinned at commit `11c0be2200116a3635880d600fd6953899cc51a3`). Each was processed by this project: converted to 44.1 kHz, trimmed, turned into a seamless loop, loudness-matched and re-encoded as Ogg Vorbis (`scripts/sounds`, see `BUILDING.md`). The original recordings are not stored in this repository; they are fetched from Moodist and checked by sha256 when the sounds are rebuilt.

Moodist's README at that commit states, under "License":

> This project is licensed under the **MIT License** - see the [LICENSE](https://github.com/remvze/moodist/blob/11c0be2200116a3635880d600fd6953899cc51a3/LICENSE) file for details.

and, under "Third-Party Assets":

> Some sounds used in this project are sourced from third-party providers and **are subject to different licenses**:
> - Sounds licensed under the **Pixabay Content License**: [Pixabay Content License](https://pixabay.com/service/license-summary/)
> - Sounds licensed under **CC0**: [Creative Commons Zero License](https://creativecommons.org/publicdomain/zero/1.0/)

Moodist does not state which sound falls under which of the two licences, and the individual uploads behind the recordings have not all been traced. No licence is stated here for any recording that has not been traced.

### Binaural Beats
The six binaural beat loops (`assets/sounds/binaural/`) are generated by `scripts/sounds` as exact sine tones (one carrier per ear, whole-Hz frequencies, 10 s, seamless). They contain no third-party recording.

### Noise
The four noise loops (`assets/sounds/noise/`: brown, green, pink and white) are generated by `scripts/sounds` (random-phase inverse FFT shaped to a stored band, fixed seed, 10 s, seamless). They contain no third-party recording.

### Internet Radio
Radio stations use the [Radio Browser API](https://www.radio-browser.info) for station search and metadata.

## Build Tools

The sounds are produced with the following tools; none of them ships in the app:
- [FFmpeg](https://ffmpeg.org) with the libvorbis encoder ([Xiph.org](https://xiph.org/vorbis/)), which encodes and decodes the Ogg Vorbis files
- NumPy, SciPy, SoundFile and pyloudnorm for the signal processing and loudness measurement
